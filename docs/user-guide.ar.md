# دليل الاستخدام

[English](user-guide.md) · [العودة إلى الصفحة الرئيسية](../README.ar.md)

## الميزات

| الميزة | ماذا تفعل |
| --- | --- |
| **منع تكرار صوت الميكروفون** | عندما يعيد Discord تشغيل صوتك داخل جهاز Sonar Microphone أثناء مشاركة الشاشة، يكتم SonarFix هذا التشغيل المكرر وحده. أما مدخل الميكروفون نفسه فيبقى كما هو دون كتم. |
| **تعطيل Game & Chat في Sonar** | يعطّل مخرجي Game & Chat إذا لم تكن تستخدمهما، ويُبقيهما معطّلين. تختار جهاز الإخراج الفعلي (مثل سماعتك)، وتقرر بنفسك إن كان سيصبح المخرج الافتراضي في Windows. |
| **فحص أجهزة الصوت** | فحص للقراءة فقط يوضح حالة Sonar ومخرجي Game & Chat وميكروفون Sonar وجهاز الإخراج المختار. لا يغيّر أي جهاز. |
| **أيقونة اختيارية في شريط النظام** | فيها فتح وإيقاف وإنهاء. متوقفة افتراضيًا، ولا تعتمد عليها مراقبة الصوت. |
| **التحقق من التحديثات** | يبحث عن إصدار مستقر أحدث في GitHub Releases عند طلبك، أو مرة يوميًا إن فعّلت ذلك. يعرض الإصدار فقط، ولا ينزّل أو يثبّت أي شيء، وفشل التحقق لا يؤثر على عمل الصوت. |
| **التشغيل مع Windows** | اختياري. يشغّل العامل في الخلفية بصمت عند تسجيل الدخول. |
| **العربية والإنجليزية** | البرنامج والمثبّت يبدّلان اللغة فورًا بزر A/ع، مع دعم كامل للاتجاه من اليمين إلى اليسار. |
| **استعادة إعدادات الصوت** | يوقف ميزتي الصوت ويعيد كل تغيير صوتي سجّله SonarFix. |
| **التشخيص والسجلات** | يفتح مجلد السجلات أو يصدّر ملف تشخيص ترفقه ببلاغ خطأ. لا يُرسل أي شيء تلقائيًا. |
| **المثبّت وأداة الإزالة** | مثبّت للمستخدم الحالي فيه تحديث وتعديل وإزالة. الإزالة تستعيد تغييرات الصوت المسجلة قبل حذف الملفات. |

كل تغيير يجريه SonarFix على الصوت يُسجَّل، ويمكن التراجع عنه عبر **استعادة إعدادات الصوت** أو بإزالة البرنامج.

## التحقق من الملف

كل إصدار يذكر بصمة SHA-256 لملف التثبيت، لتتأكد من سلامة الملف:

<div dir="ltr">

```powershell
Get-FileHash .\SonarFix-Setup-1.0.0.exe -Algorithm SHA256
```

</div>

## التثبيت

1. شغّل `SonarFix-Setup-1.0.0.exe`. لا يحتاج صلاحيات المسؤول، ويُثبَّت لحسابك فقط.
2. اختر الميزات التي تريدها. إذا فعّلت **تعطيل Game & Chat** فاختر جهاز الإخراج الذي تسمع منه فعلًا.
3. اضغط **تثبيت**. يعمل SonarFix في الخلفية، ويبدأ مع Windows إن اخترت ذلك.

إذا كان SonarFix مثبّتًا من قبل، يعرض المثبّت ثلاثة خيارات: **تحديث** مع الاحتفاظ بإعداداتك، أو **تعديل** لمراجعة الميزات أولًا، أو **إزالة التثبيت**.

المثبّت والبرنامج غير موقّعين رقميًا حتى الآن، لذلك قد يظهر تحذير SmartScreen في أول تشغيل. راجع [حل المشكلات](troubleshooting.ar.md).

## إزالة التثبيت

استخدم **الإعدادات الإضافية ← إزالة SonarFix**، أو من Windows: *الإعدادات ← التطبيقات ← التطبيقات المثبّتة ← SonarFix ← إلغاء التثبيت*. يطلب SonarFix التأكيد، ثم يستعيد تغييرات الصوت التي سجّلها، ثم يحذف ملفاته. إذا فشلت الاستعادة فلا يُحذف شيء. تبقى تفضيلاتك في `%LOCALAPPDATA%\SonarFix`.

## القيود المعروفة

- النسخ غير موقّعة رقميًا.
- كشف تكرار الصوت لا يتصرف إلا عندما يكون مسار صوت Discord واضحًا، وإلا فلا يفعل شيئًا ويسجّل السبب.
- قد تحتاج إلى ضبط جهاز الإخراج في Discord نفسه بعد تعطيل Game & Chat.
- إذا كانت أيقونة شريط النظام مفعّلة، يطلب المثبّت إغلاق SonarFix قبل التحديث. اختر **إنهاء** من الأيقونة ثم شغّل المثبّت مجددًا.
- جُرّب مع إعداد سماعة SteelSeries واحد على Windows 11، ولم يُتحقق من سماعات أو إصدارات SteelSeries GG أخرى.
