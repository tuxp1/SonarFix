# SonarFix v1.0.0 — Initial Stable Release

The first stable release of SonarFix, a lightweight Windows utility that prevents duplicate microphone audio in Discord and lets you disable unwanted SteelSeries Sonar audio devices.

> SonarFix is an independent, unofficial community project and is not affiliated with, endorsed by, or sponsored by SteelSeries or Discord.

## Features

- **Prevent Duplicate Mic Audio:** stops people hearing you twice while you screen share in Discord. Only the duplicate Discord playback stream is muted; your microphone input is never muted.
- **Disable Sonar Game & Chat:** turns off the Sonar outputs you don't use and keeps them off, with your chosen headset or speakers as the output.
- **Audio Device Health Check:** read-only status of every device SonarFix relies on.
- **Optional System Tray** (off by default) with Open, Stop and Exit.
- **Start with Windows**, optional.
- **Update Checker** for new stable releases on GitHub. It never downloads or installs anything, and a failed check does not affect audio.
- **Arabic and English**, switched instantly in the app and the installer.
- **Restore Audio Settings**, **Diagnostics & Logs**, and an **installer and uninstaller** that restores recorded audio changes before removing files.

## Fixes and improvements since the preview builds

- Installer redesigned to match the app, with Update, Modify and Uninstall options when SonarFix is already installed.
- Compact Advanced Settings; the window adapts its height to the content.
- The status line follows what the background worker actually reports, including "Audio device unavailable" when the Sonar Microphone is missing.
- Save Changes is only enabled when there is something to save.
- Arabic text keeps "Game & Chat" in its English order.

Settings from earlier SonarFix builds are kept when you install this version over them.

## Known limitations

- The installer and app are not code-signed, so Windows SmartScreen may warn on first run. Verify the checksum below.
- Duplicate-audio detection only acts when the Discord audio route is unambiguous; otherwise it does nothing and logs why in `SonarFix.log`.
- Discord may need its own output device set after Game & Chat are disabled.
- With the tray icon on, the installer asks you to close SonarFix before updating; choose Exit from the tray icon and run it again.
- Windows 10/11 x64 only. Tested with one SteelSeries headset setup on Windows 11; other headsets and SteelSeries GG versions have not been verified.
